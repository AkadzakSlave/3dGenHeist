# Wild Bunch — Steam Co-op Setup Guide

## Общая информация
- **Проект:** Wild Bunch (VOLGIANT)
- **Сетевая модель:** Listen Server (P2P через Steam Datagram Relay / Steam Networking Sockets)
- **Steam App ID для тестов:** `480` (Spacewar)
- **Количество игроков:** 1–4
- **Сетевой стек:** Mirror + FizzySteamworks + Steamworks.NET

## Требования для локального запуска и тестирования
1. Запущенный клиент **Steam** на компьютере (хотя бы под одним аккаунтом для одиночного теста).
2. Наличие файла `steam_appid.txt` со значением `480` в корне проекта (рядом с исполняемым файлом `.exe` в билде или в корневой папке проекта при запуске из Unity).
3. Для мультиплеерного теста нужны **2 разных аккаунта Steam** на двух разных ПК (или на одной машине через виртуальную машину / sandbox). Оба аккаунта должны быть добавлены друг к другу в друзья.

## Структура лобби
- Лобби создаётся со статусом **Friends Only** (Только для друзей) либо по приглашению.
- Для изоляции от сторонних игроков Spacewar используются обязательные метаданные лобби:
  - `game_id`: `volgiant_wild_bunch`
  - `game_version`: текущая версия игры
  - `protocol_version`: версия сетевого протокола
  - `host_steam_id`: Steam ID создателя сессии

## Настройка сборки (Standalone Windows x64)
- В каталог со собранным `.exe` автоматически копируется `steam_appid.txt` (480) для тестовых сборок.
- Перед релизом в Steam файл `steam_appid.txt` удаляется, а в `NetworkSessionConfig` задаётся релизный App ID студии.
