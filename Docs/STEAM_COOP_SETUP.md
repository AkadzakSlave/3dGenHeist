# Wild Bunch — Steam Co-op Setup & Testing Guide

## 1. Общие сведения
- **Проект:** Wild Bunch
- **Студия:** VOLGIANT
- **Платформа:** Windows PC (x64)
- **Сетевая модель:** Server-Authoritative Listen Server (P2P через Steam Datagram Relay / Steam Networking Sockets)
- **Steam Test App ID:** `480` (Spacewar)
- **Количество игроков:** 1–4
- **Сетевой стек:** Mirror 96.11.6 + FizzySteamworks 6.0.1 + Steamworks.NET 2025.165.0

---

## 2. Предварительные требования для тестирования
1. **Клиент Steam:** должен быть запущен на компьютере под активным аккаунтом.
2. **Файл `steam_appid.txt`:** должен находиться в корневой папке проекта (при запуске из Unity Editor) либо в одной папке с собранным файлом `WildBunch.exe` (в Standalone билде). Содержимое: `480`.
3. **Одиночный запуск без Steam:** если Steam выключен, игра **не крашится** — `SteamBootstrap` выводит предупреждение и переключается в локальный `Offline Mode` для одиночной игры.
4. **Сетевой тест (2–4 игрока):**
   * Требуются **разные компьютеры** и **разные аккаунты Steam**.
   * Аккаунты должны быть взаимно добавлены в список друзей Steam (режим лобби по умолчанию — Friends Only).
   * Никакого проброса портов, VPN (Radmin, Hamachi) и ручного ввода IP-адресов не требуется — трафик идет напрямую через NAT-punchthrough и релеи Valve.

## 3. Как запустить кооператив и пригласить друзей

### Способ 1: Через внутриигровую панель отладки [F8] (Самый быстрый для тестов)
1. Запустите игру (в Unity или Standalone билде).
2. Нажмите клавишу **F8** на клавиатуре — откроется сетевой оверлей *Wild Bunch — Network Co-op Debug*.
3. **Хост:** Нажмите кнопку `Create Steam Lobby (Friends Only)`.
   * Создастся лобби в Steam с App ID 480 и метатегами `volgiant_wild_bunch`.
   * Автоматически запустится Listen Server на базе `FizzySteamworks`.
4. **Приглашение:** Нажмите кнопку `Invite Friends (Overlay)`.
   * Откроется официальный оверлей Steam со списком друзей.
   * Отправьте приглашение другу.
5. **Клиент:** Получив приглашение в чате Steam, друг нажимает кнопку **«Присоединиться к игре»** (Join Game).
   * Клиент автоматически считывает Steam ID лобби, подключается к сокету хоста и спавнит своего персонажа на Базе.

### Способ 2: Через Главное меню
1. В главном меню выберите «Создать лобби» / «Кооператив».
2. После входа на Базу друзья могут присоединиться через оверлей Steam (Shift+Tab -> Друзья -> Присоединиться к игре).

---

## 4. Сборка Standalone Windows x64
Для сборки тестового билда для команды:
1. В Unity выберите **File -> Build Settings...**
2. Платформа: **Windows (x64)**.
3. В список сцен добавьте:
   * `Assets/Scenes/Game.unity` (или стартовая сцена проекта).
4. Нажмите **Build**.
5. **ВАЖНО:** После завершения сборки убедитесь, что файл `steam_appid.txt` (со значением `480`) скопирован в директорию рядом с `WildBunch.exe`. Без него Steamworks не сможет подключиться к App ID 480 вне редактора.

---

## 5. Горячие клавиши для тестирования
- **F8** — открыть/скрыть панель сетевой отладки (RTT/пинг, статус лобби, список игроков, кнопки подключения).
- **F6** — принудительный запуск штурма полиции (для проверки синхронизации волн охраны на сервере).
- **F7** — принудительный вызов патруля охраны.
- **ESC** — пауза (в мультиплеере локальный ввод отключается, но физика и другие игроки **не замораживаются**).
